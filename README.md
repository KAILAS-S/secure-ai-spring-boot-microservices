# secure-ai-spring-boot-microservices
Production-oriented Java 21 and Spring Boot 3 microservice demonstrating secure REST APIs with Keycloak OAuth2/JWT, PostgreSQL, Kafka event-driven communication, Transactional Outbox/Inbox, idempotent processing, DLT, Flyway migrations, and Prometheus monitoring. Focused on reliable messaging, distributed systems, and scalable microservices.
